📱 Usage professionnel sur appareil personnel (BYOD)

En utilisant FreshControl sur votre appareil personnel dans le cadre de vos missions, vous reconnaissez :
• Avoir été informé(e) par votre employeur de cette modalité d'usage et l'avoir acceptée volontairement ;
• Que l'application est une PWA qui n'installe aucun logiciel natif et n'accède pas à vos contacts, photos personnelles, SMS ou autres applications ;
• Que vous restez seul(e) propriétaire de votre appareil et responsable de sa configuration générale.

📋 Données effectivement traitées

L'application traite les catégories de données suivantes :
• Géolocalisation (latitude/longitude) — pour identifier le magasin, après votre consentement explicite à chaque session ;
• Photographies de codes-barres et d'emballages — décodées localement par votre navigateur, non transmises ;
• Données produits que vous saisissez : nom, code-barres, DLC, type, magasin, auteur du scan ;
• Compte utilisateur : nom, identifiant, mot de passe (stocké haché SHA-256 + sel), rôle, rayon ;
• Adresses e-mail que vous renseignez pour les rappels (optionnel) ;
• Adresse postale du magasin (optionnel) — géocodée via OpenStreetMap.

💾 Stockage & destinataires

Stockage principal : localStorage du navigateur, sur votre appareil. Les données ne quittent pas l'appareil sans action de votre part.
Services tiers chargés à l'ouverture (sans transfert de données métier) : jsDelivr (CDN du décodeur ZXing), Google Fonts, OpenStreetMap/Nominatim (uniquement lors d'une recherche d'adresse).
Backend optionnel (si configuré par l'administrateur de votre magasin) : Google Sheets / Google Apps Script pour la synchronisation du catalogue et l'envoi d'alertes e-mail. Dans ce cas, les destinataires sont les services Google et les adresses e-mail que vous saisissez.
Hébergement : Vercel Inc.

⏳ Durée de conservation

Les données sont conservées tant que vous ne les supprimez pas (bouton « Réinitialiser » de l'app, ou nettoyage des données du navigateur). La géolocalisation ponctuelle n'est pas conservée — seul l'appariement au magasin est utilisé pour la session. Les comptes utilisateurs sont conservés tant que l'administrateur ne les supprime pas.

Vous disposez des droits d'accès, de rectification, d'effacement, de limitation, de portabilité, d'opposition et du droit de retirer votre consentement à tout moment (art. 15 à 22 RGPD). Vous pouvez également introduire une réclamation auprès de la CNIL (cnil.fr).

4. Politique de confidentialité (RGPD)

4.1. Responsable de traitement

Le responsable de traitement est [Raison sociale de l'éditeur]. L'employeur de l'Utilisateur agit en qualité de co-responsable lorsque l'usage de l'Application s'inscrit dans une mission professionnelle pour son compte (art. 26 RGPD).

4.2. Données traitées et finalités

Les catégories de données traitées et les finalités poursuivies sont les suivantes :

  • Données d'authentification (nom, identifiant, mot de passe haché, rôle, rayon) — finalité : sécurisation de l'accès. Base : exécution de mesures précontractuelles / contrat (art. 6.1.b RGPD).
  • Géolocalisation ponctuelle — finalité : associer la session au magasin de rattachement. Base : consentement explicite à chaque session (art. 6.1.a). La position n'est pas conservée.
  • Photographies de codes-barres et d'emballages — finalité : décodage local du code-barres et identification du produit. Traitées uniquement dans le navigateur de l'Utilisateur, non transmises.
  • Données produits (code-barres, libellé, DLC, type, magasin, auteur) — finalité : suivi des dates de consommation. Base : intérêt légitime de l'employeur (art. 6.1.f) à prévenir le gaspillage et les non-conformités sanitaires.
  • Adresses postales et e-mail renseignées dans la configuration — finalité : géocodage du magasin et envoi d'alertes. Base : exécution du contrat / consentement.

4.3. Stockage et destinataires

Par défaut, l'ensemble des données saisies est stocké localement dans le navigateur (localStorage / sessionStorage) de l'Utilisateur. Aucune base de données centralisée n'est mise en œuvre par l'Application elle-même.

Les services tiers chargés à l'ouverture, sans transfert de données métier, sont :

  • jsDelivr (Cloudflare / Fastly) — chargement de la bibliothèque ZXing pour le décodage local des codes-barres.
  • Google Fonts — chargement de la police Nunito.
  • Nominatim / OpenStreetMap (OpenStreetMap Foundation, Royaume-Uni) — géocodage d'adresses postales lors de la configuration d'un magasin.

Si l'administrateur configure un backend optionnel : Google Sheets et Google Apps Script (Google Ireland Limited) reçoivent alors les données de catalogue et, le cas échéant, les sauvegardes de scans et les rappels e-mail. Les transferts vers Google sont encadrés par les Clauses Contractuelles Types.

4.4. Durées de conservation

  • Données stockées localement : conservées tant que l'Utilisateur ne les supprime pas (bouton « Réinitialiser » de l'Application ou nettoyage des données du navigateur).
  • Géolocalisation : non conservée — utilisée uniquement pour la durée de la session.
  • Comptes utilisateurs : conservés tant que l'administrateur ne les supprime pas.
  • Données envoyées vers Google Sheets / Google Apps Script (si activé) : régies par les durées propres de l'administrateur du compte Google.

Les mots de passe sont stockés sous forme hachée (SHA-256 + sel aléatoire par utilisateur).
